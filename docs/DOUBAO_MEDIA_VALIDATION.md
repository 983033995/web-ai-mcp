# 豆包图片与视频生成接入验证

2026-10-19（Asia/Shanghai），用户明确要求在当前豆包 HTTP 适配器中加入图片和视频生成。测试使用本人已登录账号、合成几何体提示词，无人物或私有文件。Cookie、完整请求、响应与生成地址仅保存在 Git 忽略的 `.validation-doubao-media/` 中，目录权限 `0700`，文件 `0600`，未写入 Git。浏览器使用 ego-browser；未使用 Playwright。

## 已观察的协议

| 环节 | 观察与实现 |
| --- | --- |
| 图片提交 | 仍为 `POST /chat/completion`；`chat_ability.ability_type=3`，JSON 字符串参数内 `ability_type=1`，模型为 `Seedream 5.0 Flash` |
| 视频提交 | 同一聊天端点；`ability_type=17`，参数包含 `model=seedance_v2.5`、`ratio`、整数 `duration`、`camera_movement=fixed` |
| 图片结果 | `2074/creation_block.creations`；`type=1`，`image.status=1` 是观察到的等待状态，`status=2` 含 `image_ori.url` 和尺寸；后续卡片替换旧状态 |
| 视频结果 | 网页首次要求确认；同会话确认后先返回说明文字，稍后另发助手消息；`type=2`，`video.status=3` 含 `download_url`、字符串宽高及数值时长 |
| 异步查询 | 网页重载实际调用 `POST /im/chain/single`，命令 `3100`、`pull_singe_chain_uplink_body`、最近 20 条消息；`Content-Type` 必须保留 `encoding=utf-8`，否则返回“不支持编码类型” |
| 额外 SSE 事件 | 本次响应含 `DOWNLINK_CMD`，`cmd=310` 的 `chunk_update_downlink_body.interrupt_info`；只接受观察到的结构，不静默忽略未知命令 |

图片工具当前仅开放 `auto` 和 `1:1`；视频比例依据网页菜单，时长滑块为 4–30 秒。模型名称与参数是当次网页观察值，不属于公开稳定 API。没有生成聊天签名或设备指纹，没有修改网站额度、验证码或风控规则。

## 验收边界

- 网站可能要求补充提示或确认参数；返回 `no_media_returned` 只说明没有媒体，不证明任务已经排队。通过 `doubao_chat` 在同会话回答后，再显式查询。工具不会自动确认、重发或轮询。
- 成功卡片中的 URL 才作为结果返回；未知媒体状态标为 `unavailable`。网页控制额度、计费与输出规格。本次仅验收默认图片模型与四秒视频，其他比例、时长未逐项真实生成。
- 地址可能过期，当前不自动下载。首轮验收仅含文生图、文生视频；后续模型、比例、风格和参考图扩展见下节。图生视频、视频延长及局部蒙版编辑尚未实现。
- 测试证明当次本人账号的 HTTP 产品链路可用，不保证未来私有接口或风控行为不变。出现验证要求即阻断后续客户端请求，不通过账号轮换、自动解验证码或重复提交继续测试。
- 本次未发布 npm 版本；v0.1.2 不包含这些豆包能力。

## 模型与生成参数补充验收

同日用户继续要求可选择图片/视频模型、视频默认 Seedance 2.0 Fast，以及图片比例、风格、参考图和视频时长、比例。模型名称与网站值来自本人网页实际下拉菜单及 `/alice/slot/action_bar_v3/get_item_conf` 配置，没有凭名称猜测 ID。风格映射与参考图请求另行对照当前网页捕获。

| 类型 | 工具 `model` 值 | 网站值 | 约束 |
| --- | --- | --- | --- |
| 图片 | Seedream 5.0 Flash（默认） | Seedream 5.0 Flash | 本次未逐个模型生成所有规格 |
| 图片 | Seedream 5.0 Pro | Seedream 5.0 Pro | 访问权限与消耗由网站决定 |
| 图片 | Seedream 4.5 | Seedream 4.5 | 同上 |
| 图片 | Seedream 4.0 | Seedream 4.0 | 实际 MCP 显式选择及参考图生成通过 |
| 视频 | Seedance 2.0 Fast（默认） | seedance_v2.0 | 4–15 秒；实际 MCP 默认请求与完成结果通过 |
| 视频 | Seedance 2.5 | seedance_v2.5 | 4–30 秒；首轮真实生成通过 |
| 视频 | Seedance 2.0 | seedance_v2.0_std | 4–15 秒；菜单与配置、确定性请求测试 |
| 视频 | Seedance 2.0 Mini | seedance_v2.0_mini | 4–15 秒；菜单与配置、确定性请求测试 |

图片比例为 `auto`、`1:1`、`2:3`、`3:2`、`3:4`、`4:3`、`9:16`、`16:9`；视频比例沿用 `auto`、`1:1`、`3:4`、`4:3`、`9:16`、`16:9`、`21:9`。风格枚举来自网页列出的 32 项，包括水彩画、油画、动漫、平面插画等；例如水彩画映射到 `skill_image_styles_watercolor`。每次调用选择模型，省略使用默认，不读取网站偏好或静默沿用上一次模型，不在失败时换模型。

参考图只接受允许目录内的 PNG/JPEG/WebP，1–5 张、每张 10 MiB、合计 20 MiB。图片上传采用 `prepare_upload` 的 `resource_type=2`，复用正常临时授权与 CRC/提交链路；提交结果须确认分配的源 URI、有效图片 URI、格式与尺寸。`10052/attachment_block` 中 `type=1` 的图片附件与文本分成两条消息，匹配网页实际请求。网页 Cookie 不发送到存储域名，授权与参考图不进入会话存储。

实际验证包括：

- 网页上传本地合成蓝色三角形，选择 Seedream 4.0、水彩画和 3:4，得到 1728×2304 完成图片，产品 SSE 回放通过。
- 真实 MCP 明确选择 Seedream 4.0 生图通过；视频省略 `model`，捕获的产品请求实际发送 `seedance_v2.0`，随后在重启后只读查询中获得完成视频。
- 真实 MCP 独立上传另一张合成绿色菱形参考图，上传 URI 不同于浏览器参考图；请求中模型、风格、比例和图片附件均确认。首次仅传结构化参数时得到方图；按网页行为将所选比例、风格同时写入可见指令后，单次复测得到 1728×2304 的 3:4 完成图片。
- strict 类型检查、构建及 114 项确定性测试通过；测试覆盖模型映射、默认 Fast、同会话切换、时长边界、比例/风格参数、图片授权/CRC/提交、全组图片上传前校验、目录/符号链接限制及验证码后阻断。

这些结果只证明所列代表场景的当前本人账号链路。其他模型的全部风格/比例组合及视频最长时长没有逐项实测，账号套餐、额度、输出尺寸与可用模型仍由网站控制。

## 2026-10-20：下载保存与图片官方无水印

通过真实 stdio MCP 对本人已有测试资源执行 `doubao_media_status` 和新增 `doubao_download_media`，未调用任何生成工具：

- 原始图片：`image/png`，2,939,902 字节，1728×2304；本机打开可见右下角“豆包 AI 生成”。
- 图片 `without_watermark=true`：官网 `/creativity/resource/get_without_watermark` 明确确认权限和相同资源 URI；保存 `image/png`，2,931,001 字节，1728×2304；本机打开确认右下角可见水印消失，构图一致。只声明官网提供的可见水印移除，不声明删除文件内的所有元数据或其他标识。
- 原始视频：`video/mp4`，88,680 字节；ffprobe 确认 HEVC、720×720、4.063991 秒及 AAC 音轨。
- 视频请求 `without_watermark=true`：返回不支持，未调用图片无水印接口、未降级下载，也没有生成新视频。视频官方无水印能力仍未验证。

下载保存到私有且 Git 忽略的验证目录；凭据、真实媒体 URL、资源 ID、会话映射、原始文件与本机路径不提交。确定性测试另覆盖无目录时不发请求、稳定媒体选择、权限拒绝、资源不匹配、凭据不外发、跳转、类型/大小检查、取消和部分文件清理。
